
# 🐦 Flappy Bird Game in C

A simple Flappy Bird clone written in C using the **iGraphics** and **iSound** libraries.

---

## 📌 Features

- Bird animation and smooth jumping physics
- Three difficulty levels: Easy, Medium, Hard
- Real-time scoring and collision detection
- Persistent leaderboard system (saved to file)
- Background music and sound effects

---

## 🎮 How to Play

- Press `SPACE` or click the mouse to flap the bird
- Avoid obstacles and survive as long as possible
- Score increases every time you pass a pipe
- Game over if you hit a pipe or the ground

## ⚙️ How to Run

1. Clone or download the repository.
2. Open the project in Code::Blocks or any C IDE.
3. Make sure `iGraphics.h` and `iSound.h` are included and configured.
4. Build and run the project.
